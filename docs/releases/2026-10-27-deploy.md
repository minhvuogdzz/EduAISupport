## Các chỗ lệch được xử lý

- Bản chạy local cũ vẫn ở `brain-snapshot`, Vite 5173 + API 8000. Nguồn bàn giao được chốt theo main có BRAIN-1/REL-1; image chứa web HTTP tương ứng và in revision để kiểm bản đang chạy.
- CI #119 trượt vì fixture gọi API cần DB nhưng không override DB: sửa bằng DB trong bộ nhớ, không bỏ test hoặc chạm dữ liệu thật. `create_app` gọi nhiều lần làm auth router tích lũy route: mỗi app tạo router riêng.
- Gói ban đầu chỉ có DB, thiếu tệp gốc/âm thanh. Thêm storage transfer; giữ documents/voice/runtime caches, loại backup cũ, preview chưa duyệt và model weights VieNeu ở `voice/hf`.
- Entrypoint ban đầu tạo chỉ mục kể cả khi chạy dry-run: chỉ khởi tạo khi chạy API; kiểm archive không ghi DB.
- Ghi rõ tính chất bộ não: bật LLM, có model dự phòng; validator, quota và trần 40 lần gọi vẫn có thể đưa lượt về nội dung đã duyệt. Không coi số test xanh là chứng minh mọi phản hồi đã tự nhiên.
- GitHub công khai: DB/storage và khóa không đưa vào git hoặc image. Xuất gói riêng có hash để giao DevOps.

## Kiểm chứng

- REL-1: 1.868 test Python đạt, 37 Atlas test skip khi không cấu hình; API/web CI xanh trước khi merge.
- DEPLOY-1: 1.899 test Python đạt, 37 Atlas test skip; 213 test web đạt; lint, format, TypeScript và production build đạt. Test mới kiểm round-trip DB/tệp, dữ liệu ngày giờ/ID, đích đã có dữ liệu, `_id` lặp, archive hỏng/path traversal/symlink và không ghi khi dry-run.
- CI `docker` dựng thật trên Linux từ checkout, import DB/storage giả, kiểm web cùng origin/DB/tài khoản/file payload và từ chối import lần hai với mã 2. Merge chỉ sau khi cả api/web/docker xanh. Máy local không có Docker nên không nhận là đã chạy Docker trên máy này.
- Nguồn DB thật chỉ được đọc để xuất; kiểm round-trip vào DB trong bộ nhớ. Không test, seed, tạo tài khoản hay migration vào DB nguồn.

Chất lượng lời gia sư cần người đọc chấm; mẫu so model trước đó chỉ 26 lượt. Giữ trạng thái chờ duyệt của các DI/nội dung (DI-76…84) và preview FIG-1; không tự xuất bản lại kế hoạch.
